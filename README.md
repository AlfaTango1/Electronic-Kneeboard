# Flight Mission Navigator

Программа планирования и выполнения полётных заданий: маршруты, ППМ, зоны, аэродромы, навигационные расчёты, полёт по GPS.

Из этого репозитория GitHub автоматически собирает:

- **Android-приложение (APK)** — устанавливается на телефон, работает без интернета и держит экран включённым;
- **веб-версию на GitHub Pages** — открывается по ссылке `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`, устанавливается на главный экран телефона (Android и iPhone).

---

## 1. Создать репозиторий

1. Зарегистрируйтесь на <https://github.com> (если ещё нет аккаунта).
2. Справа вверху нажмите **+** → **New repository**.
3. **Repository name** — например `fmn`.
4. Выберите **Public** (бесплатный GitHub Pages работает только для публичных репозиториев; ваши задания и маршруты в репозиторий не попадают — они хранятся только на телефоне).
5. Нажмите **Create repository**.

## 2. Загрузить файлы

Распакуйте архив `fmn-app.zip` на компьютере.

**Через браузер (проще):**

1. В новом репозитории нажмите **uploading an existing file** (или **Add file → Upload files**).
2. Перетащите **всё содержимое** распакованной папки `fmn-app` (не саму папку), включая скрытую папку **`.github`**.
   - Windows: папка `.github` видна обычно. macOS: в Finder нажмите `Cmd+Shift+.`, чтобы увидеть скрытые папки.
3. Внизу нажмите **Commit changes**.
4. Проверьте, что в репозитории есть путь `.github/workflows/android.yml`. Если его нет — создайте файл вручную: **Add file → Create new file**, имя `.github/workflows/android.yml`, вставьте содержимое из архива. Так же для `pages.yml`.

**Через git (если умеете):**

```bash
cd fmn-app
git init -b main
git add .
git commit -m "Flight Mission Navigator"
git remote add origin https://github.com/ВАШ-ЛОГИН/fmn.git
git push -u origin main
```

## 3. Получить APK для Android

1. Откройте вкладку **Actions** репозитория. Сборка **Build Android APK** запускается сама после загрузки файлов (примерно 5–8 минут).
   - Если GitHub спрашивает разрешение на запуск Actions — нажмите **I understand my workflows, go ahead and enable them**.
2. Когда появится зелёная галочка ✅, откройте эту сборку и внизу в разделе **Artifacts** скачайте **FlightMissionNavigator-apk** (zip-архив с файлом `FlightMissionNavigator.apk`).
3. Перенесите APK на телефон и откройте его. Android попросит разрешить установку из этого источника — разрешите (**Настройки → Установка неизвестных приложений**).
4. При первом запуске разрешите доступ к **местоположению** («Точное», «При использовании приложения»).

**Постоянная ссылка на APK (релиз):** откройте **Releases → Create a new release**, в поле *Choose a tag* введите `v1.0.0` → **Create new tag** → **Publish release**. Через несколько минут APK появится в этом релизе, и его можно скачивать прямо с телефона.

> Это отладочная (debug) сборка — она полностью рабочая и устанавливается вручную. Для публикации в Google Play нужна подписанная release-сборка (можно добавить позже).

## 4. Включить веб-версию (GitHub Pages)

1. **Settings → Pages**.
2. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
3. Откройте **Actions → Publish web app (GitHub Pages) → Run workflow** (или просто загрузите любое изменение).
4. Адрес появится в **Settings → Pages**: `https://ВАШ-ЛОГИН.github.io/fmn/`.
5. На телефоне откройте адрес в Chrome (Android) или Safari (iPhone) → меню → **Добавить на главный экран**. После первого открытия программа работает и без интернета.

GPS в браузере работает только по `https://` — GitHub Pages это обеспечивает.

## 5. Обновление программы

Замените файл `www/index.html` новой версией (**Add file → Upload files** → Commit). APK и веб-версия пересоберутся автоматически. Для нового релиза создайте тег `v1.0.1`, `v1.0.2` и т. д.

Данные пользователя (задания, маршруты, справочник, карты для работы без интернета) хранятся на устройстве и при обновлении сохраняются. Перед переустановкой APK сохраните пакет: **Настройки → Перенос на другое устройство → Сохранить пакет**.

## Что внутри

| Файл | Назначение |
|---|---|
| `www/index.html` | сама программа (всё в одном файле) |
| `www/manifest.webmanifest`, `www/sw.js`, `www/icons/` | установка на главный экран и работа без интернета (веб-версия) |
| `capacitor.config.json`, `package.json` | настройки Android-приложения (Capacitor 6) |
| `scripts/prepare-www.js` | копирует картографическую библиотеку Leaflet внутрь приложения |
| `scripts/patch-android.sh` | добавляет разрешения GPS и не даёт экрану гаснуть |
| `assets/icon.png` | значок приложения |
| `.github/workflows/android.yml` | автоматическая сборка APK |
| `.github/workflows/pages.yml` | публикация веб-версии |

## Сборка APK на своём компьютере (необязательно)

Нужны Node.js 20, JDK 17 и Android Studio (Android SDK).

```bash
npm install
npm run prepare-www
npx cap add android
bash scripts/patch-android.sh
npx cap sync android
cd android && ./gradlew assembleDebug
# APK: android/app/build/outputs/apk/debug/app-debug.apk
```

## Если сборка не прошла

Откройте красную ❌ сборку в **Actions** → шаг с ошибкой → скопируйте последние строки журнала и пришлите их — по ним можно точно понять причину.

Программа — вспомогательное средство и не сертифицирована для навигации. Справочные данные (аэродромы, ВПП, граница) взяты из открытых источников — перед полётом сверяйте с действующим AIP и NOTAM.
